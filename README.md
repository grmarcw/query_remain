Telegram-бот для автоматизации учёта остатков различной продукции.  
Отображает фактический остаток продукции по запросу

---

## 🧑‍✈️ Доступные команды

<details>
<summary><code>/start</code> — заполнение первичных данных (обязательно) <small>📎</small></summary>

1. **Заполнение данных про рецепты:**

   • Запрос списка желаемых позиций для отслеживания

   • Определение товаров: выбор позиций, которые являются самостоятельными товарами, а не ингредиентами.

   • Запрос списка товаров, в состав которых входит текущая позиция.

   • Запрос количества ингредиента для каждого товара.

   • Сохранение введенной информации в базу данных

2. **Заполнение данных касаемо поставок**

    • Запрос списка названий поставок

    • Назначение продуктов: выбор поставок, в которые входит продукт

    • Сохранение в базу данных

3. **Заполнение стартового фактического остатка**

    • Ввод начальных остатков: указание количества для каждой позиции из списка.

    • Сохранение в базу данных
</details>

<details>
<summary><code>/cancel</code> — отменить текущее заполнение данных</summary>

</details>


<details>
<summary><code>/delete_or_show</code> — отобразить или удалить данные </summary>
</details>

<details>
<summary><code>/input_daily_data</code> — Заполнение основных данных <small>📎</small></summary>

1. **Уточнение даты**
2. **Заполнение данных о проданной продукции**
3. **Заполнение данных о поставках, прибывших в этот день**<br>
<small>`если поставки были:`</small>
4. **Запрос количества приехавшей продукции в этих поставках**<br>
<small>`если поставок не было или данные о количестве приехавшей продукции заполнены:`</small>
5. **Запрос списка позиций, перемещенных с других точек**<br>
<small>`если перемещения были:`</small>
6. **Запрос количества перемещенной продукции**<br>
<small>`если перемещений не было или данные о количестве перемещенной продукции заполнены:`</small>
7. **Запрос списка позиций, перемещенные на другие точки**<br>
<small>`если перемещения были:`</small>
8. **Запрос количества перемещенной продукции**<br>
<small>`если перемещений не было или данные о количестве перемещенной продукции заполнены:`</small>
9.  **Запрос списка списанной продукции**<br>
<small>`если списания были:`</small>
10. **Запрос количества каждого списанного продукта**<br>
<small>`если списаний не было или данные о количестве списанной продукции уже заполнены:`</small>
11. **Сохранение**



</details>

## 🏗️ Архитектура проекта

Проект построен по модульному принципу с чётким разделением ответственности.

```bash
├── bot/             # Telegram-модуль 
│   ├── initial/           # Модуль с хендлерами
│   │    ├── add_data.py          # Хендлеры добавление данных + обработка неизвестного сообщения
│   │    ├── changing_data.py     # Хендлеры изменения данных
│   │    ├── clarification_date   # Хендлеры для обработки даты
│   │    ├── delete_data.py       # Хендлеры для удаления данных + отображения данных из бд
│   │    ├── main_handlers.py     # Хендлеры заполнения данных
│   │    └── prompts.py           # Хендлеры для обработки команд
│   │
│   ├── buttons.py          # Настройки кнопок 
│   ├── context.py          # Файл с классом для хранения временных данных
│   ├── dispatcher.py       # Файл-диспетчер, связывающий все роутеры + запускает работу бота
│   └── states_fsm.py       # Объявление состояний FSM
│
│
├── constants/        # Текстовые сценарии 
│   ├── general.py          # Общие сообщения
│   └── stage_*.py          # Сообщения для каждого этапа ввода данных
│
│
├── core/            # Модуль с логикой проекта
│   ├── add_data.py        # Функции для добавления данных
│   ├── delete_data.py     # Функции для удаления и отображения данных 
│   ├── change_data.py     # Функции для изменения данных
│   ├── check_data.py      # Проверка корректности введенных данных
│   ├── calc_balance.py    # Расчёт фактического остатка
│   ├── renderers.py       # Форматирование данных для вывода сообщений пользователю
│   ├── handler_handlers.py # Общий обработчик пользовательского ввода
│   └── format_data_from_db.py # Запись данных из бд во временные данные для дальнейшей работы с ними
│
│
├── database/          # Модуль работы с базой данных
│   ├── create_tables.py   # Скрипт для создания таблиц
│   ├── models.py          # Модели SQLAlchemy
│   ├── queries.py         # Функции для работы с бд
│   └── session.py         # Настройка сессии для асинхронной работы
│   
│
├── tests/                 # Набор тестов для проверки бизнес-логики
│
├── .env                   # Переменные окружения
│
├── pyproject.toml         # Зависимости проекта (Poetry)
│
└── README.md              # Этот файл

```
